# GLOSSARY
- Goal run: bounded local OpenCode execution tracked under .goal-loop/runs.
- Executor: primary agent allowed to modify task code.
- Evaluator: separate read-only agent reviewing diff and evidence.
- Deterministic gate: reproducible non-LLM check.
- Governance surface: OpenCode policy, GitHub workflows/settings, ADRs, and evaluator policy.
- WSL2 scope: local Linux in WSL2; public CI on hosted Ubuntu.
