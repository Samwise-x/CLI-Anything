# CONTEXT
This repository contains independently sourced CLI-Anything harnesses; preserve their conventions. The local autonomous agent harness is project-level, WSL2/Linux-only, and separate from public contributor CI.
Invariants: GitHub-hosted Linux CI is merge authority; local hooks are bypassable; planning, execution, deterministic verification, and read-only evaluation are distinct; persist evidence; protect governance/reviewer policy; no Windows/macOS runners; recheck model availability and privacy terms.
