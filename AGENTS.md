# Local agent operating rules
This autonomous loop runs in WSL2/Linux through OpenCode CLI v2. Public CI runs only on GitHub-hosted Ubuntu. Never configure Windows or macOS execution.
Before each goal inspect CONTEXT.md, GLOSSARY.md, ADRs, repository instructions, branch, and working tree. Persist evidence under .goal-loop/runs. Planning, execution, deterministic verification, and read-only evaluation are separate stages. The executor cannot edit governance or reviewer policy. Model judgments do not replace tests or required checks.
Promotional model providers may log or train on prompts. Never send credentials, secrets, customer data, or sensitive source. Only the principal maintainer agent may publish or merge when authorized by the user and after checks and independent review. Sandboxed goal workers produce proposals and cannot publish. For autonomous goals use tools/goal_loop.py and the sandbox config in .goal-loop/; interactive model claims alone do not complete a run.
